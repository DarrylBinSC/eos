## Prompt B — Update an Existing Subject Context File

# Context

The attached Markdown file is the durable context for:

**[SUBJECT]**

The additional evidence is newer operational information.

# Task

Update the subject context without allowing recent activity to overwrite durable strategy.

Apply these rules:

- Preserve durable facts unless the evidence clearly supersedes them.
- Date all current-status changes.
- Record decisions in the historical-development section.
- Move resolved issues out of current risks.
- Do not turn every new action item into durable context.
- Identify contradictions rather than hiding them.
- Preserve Darryl's established terminology and corrections.
- Mark inferred updates as inferred.
- Update the change log.

# Output

Return:

1. A concise change summary
2. Material conflicts or validation questions
3. The complete revised Markdown file

## Prompt C — Use a Context File with Current Evidence

# Context

The attached subject-context file is durable strategic memory. The attached evidence package describes more recent activity.

# Task

Reconcile the two and produce an executive analysis.

Do not summarize everything. Identify:

- What changed materially
- What remains strategically true
- Which assumptions are now outdated
- Decisions required
- Risks or opportunities
- Cross-functional dependencies
- Where Darryl should engage
- What should be delegated
- What should be communicated

Clearly label fact, interpretation, recommendation, and validation required.

Prioritize business value and leadership leverage over urgency and activity volume.
